# Simorgh Deep Research Audit — October 9, 2026

An ecosystem audit for a free-to-run, no-KYC, self-evolving agentic AI gateway on Cloudflare's edge. Confidence markers: 🟢 well-sourced (official docs fetched this session) · 🟡 mixed/single-source (community directories or unfetched claims) · 🔴 couldn't verify. Citations are inline links to the source that states each claim; claims resting on community directories rather than fetched official pages are marked 🟡 inline.

## Executive Summary (10 bullets, brutally honest)

1. **The core idea is not novel — it's crowded.** OmniRoute (74K+ GitHub stars, MIT) already aggregates 150+ free providers behind one endpoint, and a whole ecosystem of free-LLM directories and proxies exists ([GitHub topic](https://github.com/topics/llm-gateway), [ToolkitArchive](https://github.com/Yash-Awasthi/ToolkitArchive/blob/main/FREE-ACCESS.md)). Simorgh's defensible edge must be the Cloudflare-native deploy, durable agents, and honest telemetry — not "aggregate free tiers."
2. **The free-tier ecosystem shrank materially in 2025–2026.** GitHub Models fully retired July 30, 2026 (official docs); Chutes' free tier ended March 2026 and Groq's free daily requests were cut from 14,400 to ~1,000 on most models (community-documented); Gemini's free tier is Flash-family-only per community trackers; Cerebras moved its free trial behind a verified payment method (official docs) ([GitHub docs](https://docs.github.com/en/github-models/use-github-models/prototyping-with-ai-models), [ai-free-tiers](https://github.com/Get-Ai-Tools/ai-free-tiers), [Cerebras](https://inference-docs.cerebras.ai/support/rate-limits)).
3. **The "twelve birds" folklore does not survive verification.** Official pages document recurring free allowances for several candidates — Gemini's free plan, OpenRouter `:free` (50 req/day), Cloudflare Workers AI (10K Neurons/day), all fetched this session; Groq and Cohere partially documented — but this audit has not established how many satisfy the complete recurring/no-card/permitted-use gate: signup card requirements and redistribution terms are mostly n.a. from official pages. A second tier of ~7 provisional birds (Mistral ~1B tokens/month, NVIDIA, Zhipu Flash, SiliconFlow, LLM7, Ollama Cloud, Kilo) rests on community directories and needs live signup tests. Aggregate capacity is dominated by Mistral's community-documented experiment tier — treat as 🟡.
4. **The biggest ToS landmine is pooling.** Some documentation describes free access as evaluation/prototyping-scoped (Mistral help center; NVIDIA and Cohere docs surfaced in search), and Mistral's and OpenAI's free tokens reportedly require opting in to training on your data. Commercial-use and shared-gateway redistribution restrictions remain unverified — a public multi-user gateway sitting on pooled free keys is the most plausible conflict, not a proven breach ([Cohere](https://docs.cohere.com/docs/rate-limits), [ai-free-tiers](https://github.com/Get-Ai-Tools/ai-free-tiers)).
5. **Platforms are actively hostile to third-party routing of subscription credentials.** Anthropic's January 2026 technical crackdown and April 2026 enforcement cut third-party tools off Claude subscription logins (press-documented); Google Antigravity's ToS bans third-party access outright ([VentureBeat](https://venturebeat.com/technology/anthropic-cracks-down-on-unauthorized-claude-usage-by-third-party-harnesses), [Antigravity ToS](https://antigravity.google/terms)). Never route OAuth/subscription logins — API keys only. Whether official API free tiers get the same treatment is a forecast, not an established policy.
6. **The tech stack is sound and freshly stable, with two traps.** TS7 (stable July 2026), Hono 4.13.x, Vitest 5, Wrangler 4, Node 24 LTS, DuckDB-WASM 1.5.6 are current; the traps are TS7's missing compiler API (lint tooling stays on TS6; a 7.1 API is roadmap, not a deadline) and Cloudflare's `vitest-pool-workers` not supporting Vitest 5 at release — Cloudflare now points to a new `@cloudflare/vitest-plugin` ([GitHub issue](https://github.com/cloudflare/workers-sdk/issues/15618), [Cloudflare docs](https://developers.cloudflare.com/workers/testing/vitest-integration/migration-guides/migrate-to-vitest-plugin/)). MCP Sampling is deprecated in the 2026-07-28 spec ([spec](https://modelcontextprotocol.io/specification/2026-07-28/client/sampling)).
7. **The $0 compute stack beyond LLMs is workable:** Cloudflare Workers/Cron/DOs for the always-on layer, GitHub Actions (free on public repos) for scheduled CI-shaped jobs, Kaggle (30 GPU-hrs/week, phone verification) for Python evals, Supabase Free for optional relational storage. Fly.io is no longer a free option; Render free sleeps and Vercel Hobby bars commercial use — neither fits a commercial public gateway ([GitHub docs](https://docs.github.com/en/billing/concepts/product-billing/github-actions), [aifree](https://aifree.dev/offer/kaggle-free-gpu-tpu)).
8. **Cloudflare shipped a genuinely useful trick:** Temporary Accounts (June 2026) let an agent deploy a Worker with no signup, claimable within 60 minutes — a deploy-without-an-account UX that fits Simorgh's no-KYC story ([Cloudflare blog](https://blog.cloudflare.com/temporary-accounts/)).
9. **Monetization has precedents but thin solo-dev economics.** OpenRouter (~5% take; $50M annualized early 2026 per Sacra estimates, higher figures reported later), LiteLLM (open-core: MIT proxy + paid enterprise directory), FreeLLMAPI ($19/yr catalog updates) all work — for the solo dev the realistic paths are open-core + managed deploys, catalog/telemetry subscriptions, or sponsorship. Never resell pooled free capacity.
10. **The honest 12–18 month forecast:** if built on pooled keys as a public service, it likely dies by ban or quota exhaustion within months; if built BYOK-first on Cloudflare Free with per-user quotas and paid-key escape hatches, it can survive the continuing shrinkage of free tiers — as a great personal tool and OSS reputation-builder, not a business.

## A.1 Eligibility gate

A provider qualifies as a "bird" only if all three hold:

1. **Recurring** free allowance (not a one-time signup credit),
2. **No credit card / payment method** required at signup or to activate API access,
3. An **official API** usable for automated, programmatic calls.

Notes: "no card" does not mean "no KYC" — phone verification, ID, or region locks exist (Baidu requires Chinese real-name auth). Permission for ordinary API automation does not equal permission to redistribute a free account's capacity behind a shared gateway; no provider's terms fetched in this audit explicitly authorize pooled redistribution. Personal BYOK routing is materially safer than a public pooled flock.

## A.5 ToS and aggregator risks

- **Data-training opt-ins:** Mistral's experiment tier and OpenAI's reported free daily tokens both require opting in to training on your data; Gemini's free tier reportedly uses prompts to improve Google products ([ai-free-tiers](https://github.com/Get-Ai-Tools/ai-free-tiers)). For a self-evolving agent that logs user goals, this is a privacy liability. 🟡
- **Evaluation/prototyping scoping:** some documentation describes free access as evaluation or prototyping — Mistral's help center ("evaluation and prototyping"), NVIDIA's developer-program terms (surfaced in search), and Cohere's trial/production key distinction ([Mistral help](https://help.mistral.ai/en/articles/698531-why-am-i-hitting-api-rate-limits-and-how-can-i-increase-them), [Cohere](https://docs.cohere.com/docs/rate-limits)). Commercial-use and shared-gateway redistribution restrictions remain unverified — do not infer a contractual prohibition from an evaluation-oriented product description, and do not assume permission either.
- **Redistribution silence:** no fetched provider terms explicitly authorize pooling a free account's capacity behind a shared service; none fetched explicitly prohibit API automation either. BYOK designs are materially safer than a pooled flock.
- **Ephemeral catalogs:** OpenRouter free models, Cerebras lineup, Kilo "Auto Free" rotate without notice — model IDs are volatile.
- **Geographic/KYC mismatches:** Gemini free tier reportedly unavailable in EU/UK; Chinese platforms require local identity; Anthropic trial requires SMS. 🟡

## B.2 Platform risks — the platforms are fighting back

### Anthropic: the January–April 2026 crackdowns

- **January 9, 2026:** Anthropic deployed technical safeguards blocking third-party apps from spoofing its official Claude Code client to access underlying models; developers using third-party coding tools signed in with Pro/Max subscriptions had accounts banned ([VentureBeat](https://venturebeat.com/technology/anthropic-cracks-down-on-unauthorized-claude-usage-by-third-party-harnesses), [AQ guide](https://aq.dev/guides/coding-harness-ban-risk/)).

- **Implication for Simorgh:** never route subscription/OAuth credentials (Claude Pro, Antigravity, Copilot-style plans) through the flock. The birds must be true API free tiers. This also kills several "free GPT/Claude via IDE login" tricks that older aggregator guides still recommend.

### Google Antigravity

- Additional Terms §6 prohibits "using third party software, tools, or services to access the Service" ([Antigravity ToS](https://antigravity.google/terms), [FAQ](https://antigravity.google/docs/faq/)); accounts were restricted, then restored via an appeal process after community backlash ([Google Antigravity LinkedIn](https://www.linkedin.com/posts/google-antigravity_to-the-builders-we-heard-you-we-re-welcoming-activity-7433201056307793921-yD6r)).
- The `agy` free OAuth-gated tier was already excluded from bird catalogs for exactly this reason ([OmniRoute catalog](https://github.com/mkolbas/omniroute/blob/main/docs/reference/FREE_TIERS.md)).

### Cloudflare

- No adverse policy against proxying third-party AI APIs through Workers was found in this audit — but absence of an adverse finding is not policy clearance. 🟡 Cloudflare's own AI Gateway product is itself an LLM proxy/cache, and Workers AI is Simorgh's home turf, so the platform stance is currently neutral-to-supportive.
- The real Cloudflare risk is product-level: if Cloudflare ever bundles free-tier routing into its own gateway stack, Simorgh's hosting advantage and its product converge.

### Deprecation velocity (the silent killer)

- Anthropic deprecated claude-sonnet-4-5 with retirement set 61 days later — "one day over the 60-day minimum its own policy promises, the fifth consecutive deprecation" ([pick-right news](https://pick-right.com/news/)); DeepSeek discontinued `deepseek-chat` on 2026-07-24 in favor of v4-flash ([referencesource tracker](https://referencesource.org/ai-model-deprecation-and-retirement/)).
- **Implication:** a flock must treat model IDs as cattle, not pets — automated catalog refresh and deprecation alerts are core features, not nice-to-haves.

### Free-tier enforcement trends

- Groq's 14.4K→1K RPD cut and Cerebras' card requirement (Section A) show providers actively tightening. The 2025-2026 pattern: providers launch generous free tiers during land-grab, then gut them once enterprise revenue matters. Expect every bird to degrade; the flock metaphor is correct — but plan for the whole flock to be 50% smaller within 18 months.

## B.3 Competitive verdict for Simorgh

1. **Don't compete with OpenRouter on breadth or price** — it has millions of developers and a ~5% take on a very large token flow ([AI Wiki](https://aiwiki.ai/wiki/openrouter)). Simorgh's lane is the **$0/no-KYC/self-hostable** niche OpenRouter structurally cannot serve (it needs revenue, cards for real capacity, and its free pool is 50 req/day).
2. **The real competitor is OmniRoute** (and its fork ecosystem): same idea, MIT, 74K stars, 357-provider registry. Differentiators available to Simorgh: Cloudflare-native (deploy in minutes, no server), DO-based durable agents (OmniRoute is stateless routing), honest live health telemetry, and security hygiene — the repo advertises prompt-injection guards and credential masking, so verify its posture independently rather than assuming weakness ([GitHub repo](https://github.com/diegosouzapw/OmniRoute)).
3. **Subscription-credential routing is a legal/ban minefield** after January/April 2026 — avoid entirely; it's also where most "free Claude/GPT" guides now get users banned. Whether official API free tiers face future crackdowns is a forecast, not established policy.
4. **Timing risk:** the "free tier aggregator" niche is getting crowded at exactly the moment free tiers are shrinking — a dangerous squeeze.

Portkey exited via acquisition (Palo Alto Networks) ([Future AGI](https://futureagi.com/blog/future-agi-vs-portkey-2026/)). Unify shut down its router and pivoted to agents ([LLM Gateway](https://llmgateway.io/blog/openrouter-alternatives)) — the pivot is documented, the reason is not.

## E.1 Precedents: how gateway projects actually made money

| Project | Model | Numbers | Lesson for Simorgh |
|---|---|---|---|
| **OpenRouter** | Hosted marketplace, ~5% take rate on token flow; free plan limited to 25 models/4 providers, no auto-routing ([Contrary](https://research.contrary.com/company/openrouter), [Ry Walker](https://rywalker.com/research/openrouter)) | $50M annualized revenue (early 2026, Sacra estimate; higher third-party figures reported later in the year), 25T tokens/week, $113M Series B led by CapitalG | Scale + neutrality wins — but requires paid volume; the free plan is a funnel, not the product |
| **LiteLLM** | **Open-core**: MIT-licensed proxy + `enterprise/` directory (SSO, user management, support) under a paid BerriAI license ([Atlan](https://atlan.com/know/litellm-vs-portkey-vs-bedrock-gateway/), [GitHub](https://github.com/BerriAI/litellm/blob/main/docs/my-website/docs/enterprise.md)) | ~60K stars; enterprise pricing via sales | The canonical solo-dev-friendly model: free core, paid enterprise features |
| **Portkey** | Freemium SaaS metered on recorded logs (10K/month free); paid tiers for production | **Acquired by Palo Alto Networks** (May 2026) ([Future AGI](https://futureagi.com/blog/future-agi-vs-portkey-2026/)) | Governance/LLMOps features are the acquirable asset, not routing |
| **FreeLLMAPI (catalog subscription)** | Free self-hosted router; **paid catalog updates ($19/year)** ([ToolkitArchive](https://github.com/Yash-Awasthi/ToolkitArchive/blob/main/FREE-ACCESS.md)) | 29K stars | Data-as-a-product: the catalog of working free tiers is itself monetizable |
| **nexos.ai / Vercel AI Gateway** | Provider rates + 5% markup / zero-markup platform play ([Dupple](https://dupple.com/learn/best-llm-gateways), [omidsaffari](https://omidsaffari.com/blog/best-ai-model-gateways-for-reducing-inference-costs-2026)) | — | Thin-margin volume businesses; not solo-dev territory |

## E.2 Three concrete paths for a solo dev

1. **Open-core with a paid hosted tier (LiteLLM pattern).** Keep the flock MIT and self-hostable; sell a managed one-click deploy (Cloudflare's temporary accounts make a 60-second deploy-to-own-account UX possible — the user brings their own Cloudflare account, you charge for the convenience + updates + dashboards, not for the tokens) ([Cloudflare blog](https://blog.cloudflare.com/temporary-accounts/)). BYOK materially reduces the credential-pooling risk — it does not override evaluation-only, commercial-use, or regional restrictions, so read each provider's terms for the intended use.
2. **Catalog/telemetry as the product (FreeLLMAPI pattern).** The hardest, most perishable asset is the verified, continuously probed list of live free tiers with real quotas. Sell the health-check API / updated catalog as a $19–49/yr subscription to other tool builders; keep the gateway free. The flock's own cron probes generate this data as a by-product.
3. **Sponsorship + paid support (the OSS default).** GitHub Sponsors, OpenCollective, and paid priority support/consulting on self-hosting. Realistic ceiling for a niche tool: hundreds to low thousands of dollars per month — honest, but not a company. 🟡

**What NOT to do:** resell pooled free-tier capacity (it conflicts with the evaluation/prototyping scoping of the providers whose terms were examined, and is untested for the rest), run ads in model responses, or sell user logs — each destroys the project's core promise.

# Section F — Failure Modes & Open Questions

**Confidence marker: 🟡 analysis** (the premises are cited; the forecasts are judgment)

> **What changed since early 2026:** the threat environment hardened along every axis tracked in this audit — free tiers shrank (GitHub Models retired, Chutes gone, Groq gutted), platforms banned third-party subscription routing (Anthropic January/April 2026; Google Antigravity ToS), a 74K-star open-source competitor took the niche (OmniRoute), and model deprecation velocity increased (Anthropic's 61-day retirement notice; DeepSeek's chat-model discontinuation). None of these individual events is new — the change is their cumulative direction.

## F.1 Ten ways Simorgh dies in 12–18 months (with mitigations)

1. **The birds get gutted.** The 2025-2026 record: GitHub Models retired, Chutes free tier ended, Groq cut 14.4K→1K RPD, Cerebras went card-gated, Gemini free shrank to Flash-only ([GitHub docs](https://docs.github.com/en/github-models/use-github-models/prototyping-with-ai-models), [OmniRoute](https://github.com/mkolbas/omniroute/blob/main/docs/reference/FREE_TIERS.md), [ai-free-tiers](https://github.com/Get-Ai-Tools/ai-free-tiers)). **Mitigation:** treat every provider as hours-from-dead; automated quota probes + catalog alerts; support paid BYOK keys as an explicitly separate, opt-in non-bird fallback (outside the free-tier invariant) so the flock degrades gracefully instead of dying.
2. **A provider bans the gateway for aggregating free capacity.** Some provider documentation describes free access as evaluation/prototyping-scoped (Mistral help center; NVIDIA and Cohere docs surfaced in search) ([Mistral help](https://help.mistral.ai/en/articles/698531-why-am-i-hitting-api-rate-limits-and-how-can-i-increase-them), [NVIDIA](https://docs.api.nvidia.com/nim/docs/run-anywhere), [Cohere](https://docs.cohere.com/docs/rate-limits)); commercial-use and redistribution restrictions are unverified. A popular public Simorgh on pooled keys is the most plausible conflict point. **Mitigation:** BYOK-first — ship the router, not the keys; never pre-load pooled credentials into a public deployment.
3. **Anthropic/Google-style OAuth crackdowns hit API keys next.** January/April 2026 proved platforms will ban first and publish policy after ([VentureBeat](https://venturebeat.com/technology/anthropic-cracks-down-on-unauthorized-claude-usage-by-third-party-harnesses), [kersai](https://kersai.com/anthropic-killed-third-party-claude-access-heres-every-workaround-that-still-works/)). **Mitigation:** zero subscription-credential routing, ever; document this as an invariant in the README.
4. **OmniRoute (74K stars) eats the niche.** Same idea, massive head start ([GitHub](https://github.com/diegosouzapw/OmniRoute)). **Mitigation:** differentiate on Cloudflare-native deploy (seconds, no server), durable DO-based agents, honest live telemetry, security hygiene — or merge/contribute instead of competing.
5. **Cloudflare ships the same feature.** Cloudflare already has AI Gateway, Agents SDK, and MCP-v2 evangelism ([Cloudflare blog](https://blog.cloudflare.com/mcp-v2/)). If they bundle free-tier routing, the platform advantage evaporates. **Mitigation:** be the agentic/flock layer they won't build (adversarial provider health, cross-provider memory).
6. **Free-tier ToS changes mid-project (the silent one).** Brave Search's free plan → $5/month overnight (2026-02-12) shows how fast terms flip ([OmniRoute](https://github.com/mkolbas/omniroute/blob/main/docs/reference/FREE_TIERS.md)). **Mitigation:** weekly ToS-diff checks in CI (the GitHub Actions cron).
7. **DO duration/step billing surprises on Cloudflare Free.** DO duration meters wall-clock while active; Workflows cap at 3K steps/day; a chatty self-evolving agent can hit limits with a handful of users (prior-session pricing audit). **Mitigation:** WebSocket Hibernation API, aggressive hibernation, step-budget telemetry from day one.
8. **Solo-dev burnout / maintenance cliff.** The catalog requires continuous verification; OmniRoute's own data shows free tiers change monthly. **Mitigation:** make the community the maintainer — probe results contributed via PRs; automate everything (the project is itself the demo of the self-evolving thesis).
9. **Privacy blowup via data-training opt-ins.** Mistral's and OpenAI's free tokens require training on your data; Gemini free tier uses prompts for product improvement ([ai-free-tiers](https://github.com/Get-Ai-Tools/ai-free-tiers)). A user's sensitive agent logs leaking into model training is a trust-ending event. **Mitigation:** per-bird privacy labels, route sensitive traffic only to non-training birds, document honestly.
10. **The project succeeds into a DDoS/quota-exhaustion spiral.** Public flock = shared free quotas; one viral day burns 50 req/day OpenRouter and 1K RPD Groq instantly. **Mitigation:** per-user sub-quotas in the DO, circuit breakers, waitlists — design for scarcity, not abundance.

## F.2 Five questions only live testing can answer

1. **SambaNova's true status:** does a fresh no-card account get working API access today, or is the 402 PAYMENT_METHOD_REQUIRED report correct? ([conflict documented in Section A](https://toolfreebie.com/sambanova-cloud-free-api/))
2. **Mistral's real throughput ceiling:** the Experiment tier documents ~1B tokens/month but no published RPS — what sustained RPS does a single org actually get, and does it throttle agentic traffic patterns?
3. **Enforcement behavior under aggregation:** at what request volume/pattern do Groq, NVIDIA, and Gemini free tiers soft-ban or shadow-throttle a gateway's IP/key (no provider documents this)?
4. **DO duration economics with hibernating WebSockets:** what real GB-s/day does a 10-user Simorgh flock consume with the Hibernation API — is the 13K GB-s free budget actually enough for durable agents?
5. **Cloudflare temporary accounts in practice:** can the `wrangler deploy --temporary` → claim flow really serve as a no-signup bootstrap path for end users, and does claiming preserve Workers/KV/DO state reliably? ([Cloudflare blog](https://blog.cloudflare.com/temporary-accounts/))
