## 1. MCP 2026-07-28 Specification — VERIFIED, just shipped

The PRD's "MCP 2026-07-28 spec" references (Epics 8, 9) are **correct and current**.
The spec was published **July 28, 2026** and is the biggest MCP release since remote
MCP launched. Half a billion SDK downloads/month; TypeScript + Python SDKs each
crossed 1B total downloads.

### What changed (from the official announcement + spec)

| Change | Detail | Simorgh impact |
|--------|--------|----------------|
| **Stateless protocol core** | `initialize`/`initialized` handshake and `Mcp-Session-Id` retired. Every request is self-describing (`_meta` carries protocol version, client identity, capabilities). Optional `server/discover` RPC. Requests can hit any instance behind a round-robin LB. | **Huge win** — Simorgh runs on Workers (stateless by nature). No session storage needed. Cold-start friendly. |
| **Header-based routing** | `Mcp-Method` and `Mcp-Name` HTTP headers on every request. Gateways, rate limiters, WAFs route/authorize on headers without parsing JSON bodies. | **Direct fit for Intent Shield (Epic 6)** — vet tool calls on headers at the edge, pre-loop. |
| **MRTR (Multi Round-Trip Requests)** | Replaces server-initiated `sampling/createMessage`, `elicitation/create`, `roots/list`. Server returns `resultType: "input_required"` + requests; client retries with `inputResponses`. | Enables mid-flight user confirmation over stateless transport — aligns with Simorgh's "human-confirmed boundary" (SOUL). |
| **Cacheable list results** | `tools/list`, `prompts/list`, `resources/list` + `resources/read` return `ttlMs` + `cacheScope`. | Cache tool catalogs; stable prompt caches across reconnects. |
| **Authorization hardening** | RFC 9207 `iss` validation; client credentials bound to issuer; shift from Dynamic Client Registration (DCR, deprecated) to **CIMD** (Client ID Metadata Documents). | Guides BYOK key vault design (Epic 9). |
| **Tasks extension** | Poll-based `tasks/get`, new `tasks/update` (SEP-2663). Contributed by AWS. | Long-running agent work. |
| **Deprecations (12-month offramp)** | `roots`, `sampling`, `logging`, and the legacy **HTTP+SSE transport** are deprecated. New implementations must not adopt them. | Simorgh must target **streamable HTTP only**; do not build on SSE. |
| **SDKs** | TypeScript, Python, Go, C# (Tier 1); Rust in beta. **Cloudflare Agents SDK supports 2026-07-28 from day zero** — MCP servers directly in Workers. | Story 8.2/9.2: use Cloudflare Agents SDK's MCP support rather than hand-rolling. |

### Action items for the PRD
- **Epic 8.2 / 9.2:** target the 2026-07-28 spec explicitly; use Cloudflare Agents SDK MCP bindings; no SSE transport.
- **Epic 6 (Intent Shield):** add story detail — header-based vetting of `Mcp-Method`/`Mcp-Name` is the natural edge choke point.
- **Epic 9.1 (key vault):** follow CIMD / issuer-bound credentials guidance.

Sources: blog.modelcontextprotocol.io/posts/2026-07-28/, modelcontextprotocol.io/specification/2026-07-28, blog.cloudflare.com/mcp-v2/

## 2. Web Search for Story 4.1 — DuckDuckGo Instant Answer is deprecated

**Finding:** The DDG Instant Answer API (`api.duckduckgo.com`) is effectively
**abandoned/deprecated** (community confirmed 2022; the `/api` docs page now
redirects, and Instant Answers were archived). It still answers a small set of
queries but returns **empty results for most queries** — an expected, documented
failure mode. Relying on it as the *only* search path for story 4.1 is a risk.

### No-KYC / low-friction options for a flock search bird

| Option | Free tier | KYC? | Notes |
|--------|-----------|------|-------|
| **Brave Search API** | 2,000 queries/month free | Email only, no card | Agent-native (700k OpenClaw users claim); most-cited "best for agents" 2026 |
| **Tavily** | Free tier (1,000 credits/mo) | Email, no card | LLM-ready results, citation-ready |
| **Exa** | Free tier | Email | Semantic search, good for agents |
| **Serper.dev** | 2,500 queries free once | Email | Google SERP API |
| **DuckDuckGo HTML endpoint** | Unlimited (unofficial) | None | Scrape `duckduckgo.com/html` — no key, but fragile + ToS gray. Not compliant with Simorgh's compliance line. |
| **SearxNG (self-hosted)** | Unlimited | None | True zero-KYC metasearch; runs anywhere (incl. Workers via DO is awkward) — heavy for an edge gateway |

### Recommendation for story 4.1
- Keep DDG Instant Answer as the **zero-key default** (works for facts/definitions), but
- Add **Brave Search API as an optional bird-style key** (dormant until `BRAVE_API_KEY` present) for real result lists — consistent with the flock's "dormant until key present" pattern.
- Mark the DDG-only dependency as a **known risk** in the PRD.

## 3. Cloudflare Workers AI free tier (Homā bird) — VERIFIED

- **10,000 Neurons/day free** on the Workers Free plan, resets daily. **No credit card.** Same API/response times as paid.
- Rate limits are per **model + task type** (docs updated Aug 2026) — small models like `@cf/meta/llama-3.2-3b-instruct` are the cheap path for the always-on Homā guarantee.
- Model catalog now includes strong new entrants (e.g., a 320B-total/18B-active parameter model) — **Homā's model choice should be revisited** when tuning cost/latency.
- AI Gateway free tier: 100k logs/month across gateways — useful for Epic 11 observability.

Sources: developers.cloudflare.com/workers-ai/platform/pricing, /limits, pricepertoken.com

### Data-Trust angle (Epic 7)
Mistral's free-mode training clause is a live example of why the Data Pact needs
explicit per-provider consent surfaces: a Pro-Data-Pact user's prompts could
inadvertently train a free-tier provider's model. The consent engine must be
**provider-aware**, not just data-type-aware.
